## 🛡️ Key Features & Milestones in this Cycle

### 1. Dual-Branch Staging Workflow ([#15](https://github.com/genidma/kc-spineguard/issues/15))
- Adopted strict dual-branch development standard: all feature branches and pull requests stage into `main-dev` prior to promotion into `main`.
- Updated contributing guidelines in `README.md` directing developers to `main-dev`.

### 2. IP Security Logging Architecture & Audit Viewer ([#14](https://github.com/genidma/kc-spineguard/issues/14))
- **Express Rate-Limiting & Cloud Function (`functions/index.js`)**: Rate-limited endpoint (8 req / 15 min per IP) with Firebase Admin SDK token authentication.
- **Firestore Security Rules**: Strict client-side write lock on `/users/{userId}/security_log` (`allow write: if false`), ensuring all IP records are cryptographically verified and written exclusively by backend Cloud Functions.
- **Audit Viewer (`SecurityLogView.tsx`)**: Reverse-chronological table in Profile displaying IP, browser User-Agent, and verified timestamp.
- **Verification SOP**: Documented in Issue #14 comments (cue `2026-11-14 18:36`) for Blaze plan enablement and live verification.

### 3. Multi-Factor Authentication (MFA / TOTP) Hardening ([#14](https://github.com/genidma/kc-spineguard/issues/14))
- **Cryptographic Engine (`src/lib/totp.ts`)**: RFC 6238 time-step calculation with SHA-1 HMAC and SHA-256 hashed one-time recovery backup codes.
- **Application Gate (`MfaGate` in `src/App.tsx`)**: Full clinical health route protection requiring TOTP code or backup code before access.
- **QR Code Onboarding**: Tracked under Issue #14 for visual authenticator scanning (`otpauth://totp/...`).

### 4. Ergonomic Posture Aids: Exercise Ball ([#13](https://github.com/genidma/kc-spineguard/issues/13))
- Added **Exercise ball** (stability / Swiss ball) to `POSTURE_AIDS` in `src/lib/logMeta.ts`.
- Clinical rationale: active seating engages deep lumbo-pelvic core stabilizers, promotes pelvic micro-movements, and reduces static intradiscal pressure during sitting recovery.
- Rendered with multi-select toggle chip in the Posture quick-log modal (`LogEditor.tsx`).

### 5. Medication Safety & Capacity Limits ([#16](https://github.com/genidma/kc-spineguard/issues/16) — Queued)
- Medication 24h capacity limits, max daily bounds, and unit validation.
